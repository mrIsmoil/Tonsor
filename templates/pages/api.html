Tonsor ochiq API

O‘zbekistondagi sartaroshxona va go‘zallik salonlari ma’lumotlarini boshqa dasturdan olish mumkin. Ro‘yxatdan o‘tish shart emas, kalit kerak emas — havolani ochsangiz, javob JSON ko‘rinishida keladi.

API’ni ochish Loyiha haqida
01

Asosiy qoidalar

Faqat o‘qish

API ma’lumotni faqat qaytaradi. Yozish, o‘zgartirish yoki o‘chirish uchun endpoint yo‘q — ya’ni bazaga tashqaridan zarar yetkazib bo‘lmaydi.

Kalitsiz

Ma’lumot ochiq, shuning uchun autentifikatsiya talab qilinmaydi. Har qanday saytdagi brauzer kodi ham chaqira oladi (CORS ochiq).

Tezlik chegarasi

Bitta IP uchun {{ rate_window }} soniyada {{ rate_limit }} ta so‘rov. Oshib ketsa 429 qaytadi.

Shaxsiy ma’lumot chiqmaydi. API faqat salonning o‘zi e’lon qilgan ma’lumotini beradi: nomi, manzili, xizmatlari, ish vaqti. Mijozlar, bronlar, elektron pochta, to‘lov rekvizitlari va salonni tasdiqlash kodlari javobga hech qachon qo‘shilmaydi.

Bazadagi salonlarning bir qismi ochiq manbadan yig‘ilgan: ma’lumot © OpenStreetMap hissadorlari tomonidan ODbL litsenziyasi ostida berilgan.

02

Endpointlar

GET /api/salons/

Salonlar ro‘yxati. Qidiruv, filtr va joylashuv bo‘yicha saralash bilan.

ParametrNima qiladi
qNom yoki manzil bo‘yicha qidiruv
typemen yoki women
lat, lngJoylashuv. Berilsa, natija masofa bo‘yicha saralanadi va har bir salonga distance_km qo‘shiladi
radiusKm. lat/lng bilan birga ishlaydi, eng kattasi {{ max_radius }}
limit1 dan {{ max_limit }} gacha, standart {{ default_limit }}
offsetNechtasini tashlab ketish — sahifalash uchun

03

Misollar

Terminal

curl "https://tonsor.hair/api/salons/?q=chilonzor"

JavaScript

const r = await fetch(
  "https://tonsor.hair/api/salons/" +
  "?lat=41.311&lng=69.240&radius=3"
);
const data = await r.json();
console.log(data.results);

Python

import requests

r = requests.get(
    "https://tonsor.hair/api/salons/",
    params={"lat": 41.311, "lng": 69.240,
            "radius": 3, "limit": 10},
)
for salon in r.json()["results"]:
    print(salon["name"], salon["distance_km"], "km")
