# tonsor.hair → Tonsor

Bu shoxobcha faqat domenni yo'naltirish uchun. Asosiy kod `main` shoxobchasida.

PythonAnywhere bepul tarifi o'z domenini qo'llamaydi, Namecheap'ning bepul
yo'naltirishi esa HTTPS bermaydi. GitHub Pages ikkalasini ham bepul hal
qiladi: `tonsor.hair` uchun SSL sertifikat chiqaradi va har qanday manzilni
(`/login/`, `/claim/` va h.k.) yo'li bilan birga asosiy saytga o'tkazadi.

- `index.html` — bosh sahifa
- `404.html` — boshqa har qanday yo'l (GitHub uni topilmagan sahifalar uchun beradi)
- `CNAME` — GitHub Pages'ga qaysi domen ekanini aytadi
